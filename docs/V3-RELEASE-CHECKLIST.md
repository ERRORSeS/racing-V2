## Required before claiming full specification completion

- [ ] Browser click-through, responsive/accessibility and unsaved-form guide behavior verified in a real browser. The selected managed environment does not expose its required `cua_repl.js` tool.
- [ ] Run the complete 100 seeds per country / 180 days field-density matrix and publish cancellation diagnostics. Current tests cover all countries and deterministic scenarios, not the entire requested matrix.
- [ ] Re-certify the full ten-year workload with V3's expanded histories and the full acceptance-72 end-to-end scenario. The previous v0.2 benchmark is not represented as a V3 benchmark.
- [ ] Exhaustive per-skill/trait sensitivity, family correlation, 20-generation calibration and every supported rare-variant combination.
- [ ] Full steward inquiry/disqualification/pull-up/DNF catalog, claiming settlement and every advanced class/local rule.
- [ ] Complete market negotiation, reproductive scheduling/return-service contracts, owner press and rivalry storytelling depth.
- [ ] Independent review of the simulated genetics/medical/class assumptions and exhaustive historical archive pagination.

## Hosting constraint

GitHub Pages is already public and configured to use Actions, but its `github-pages` environment currently allows deployment only from `main`. The connected GitHub credential returns 403 for branch-policy or Pages-setting changes. The PR therefore tests its branch and deploys after merge to `main`; it does not bypass environment rules or merge itself.
